0.1.2 face (head) model replacement — 2026-09-30
Change: YuNet face model replaced by PINTO model zoo 445 YOLOX-Nano, head class
(models/head_yolox.onnx, Apache-2.0). Both models now run in ONNX Runtime with
thread spinning disabled. The license-plate model is unchanged.

PASS: all 17 automated tests (Linux, Python 3.12, onnxruntime 1.22.1, OpenCV 4.11.0.86).
New test: head output decoding, source-coordinate scaling, class selection, duplicate removal.

Comparison on 323 frames (every 15th frame of 4 user dashcam videos, 720p-1440p, daytime).
Reference labels were made by eye: every candidate box from 18 detector configurations was
judged twice independently; disagreements were re-judged or ignored. 648 visible faces.
"Covered" = the mask (box + 18% margin) covers at least 80% of the face.
  0.1.1 YuNet, threshold 0.3 : 287 of 648 faces covered (44.3%), 362 false boxes
  0.1.2 head,  threshold 0.3 : 583 of 648 faces covered (90.0%),  99 false boxes
False boxes per video (0.1.1 -> 0.1.2): 720p 8 -> 19, 1080p rear 78 -> 16,
1440p event 25 -> 15, 1440p street 251 -> 49.
The 720p video has no visible faces; its false boxes increased. They are mostly
traffic lights and round road signs. Traffic mirrors are also still detected.
Heads seen from behind are now masked as well (not counted as false boxes).
License plates: 92 of 341 covered (27.0%), 0 false boxes, identical before and after.

Full analyze() time on a 4-vCPU Linux VM (decode + detection + tracking):
  1440p HEVC, 600 frames: 144.1 -> 178.1 ms/frame (+24%)
  720p, 928 frames:       139.5 -> 163.4 ms/frame (+17%)

NOT VERIFIED:
- Night, rain, tunnel or heavily tinted-glass footage (the sample videos are daytime).
- Faces missed by every evaluated detector are not in the reference labels,
  so the true coverage is lower than the figures above.
- Execution or timing on Windows.
- BlackboxMask.exe and runtime/ were not rebuilt; BUILD_MANIFEST.json hashes were
  updated only for the files changed in this version.
