Blackbox Mask 0.1.2 변경 안내

설치
이 ZIP은 전체 패키지입니다. 새 폴더에 압축을 풀고 BlackboxMask.exe를 실행합니다.
기존 0.1.1 폴더에 덮어쓸 때는 실행 중인 Blackbox Mask를 종료한 다음
ZIP의 모든 파일을 기존 폴더에 복사하고 파일 바꾸기를 선택합니다.
실행 후 창 제목과 상단에 0.1.2가 보이는지 확인하세요.

바뀐 점
- 얼굴 탐지 모델을 바꿨습니다. 얼굴만이 아니라 사람 머리 전체를 가립니다.
  옆이나 뒤를 향한 사람의 머리도 가려집니다.
- 새 모델 파일 models/head_yolox.onnx 가 필요합니다.
  이전 모델 models/face_yunet.onnx 는 더 이상 쓰지 않으며, 남아 있어도 동작에 영향이 없습니다.
- 분석 시간이 0.1.1보다 17~24% 늘었습니다(개발용 Linux PC에서 측정).
- 번호판 탐지는 0.1.1과 같습니다.

기존 프로젝트
0.1.1에서 저장한 프로젝트는 그대로 열립니다.
저장된 영역은 이전 모델의 결과입니다. 새 모델을 적용하려면 원본을 다시 분석하세요.

검증
Linux에서 테스트 17개 통과.
블랙박스 영상 4개에서 뽑은 323프레임 비교: 얼굴 가림 44% → 90%, 잘못 가린 영역 362 → 99.
자세한 내용은 VALIDATION.txt에 있습니다.
Windows PC에서의 실제 실행은 확인하지 못했습니다.

알려진 한계
- 신호등, 둥근 표지, 반사경을 머리로 잘못 가릴 수 있습니다.
- 야간, 우천 영상은 검증하지 않았습니다.
- 멀리 있는 작은 번호판은 놓칠 수 있습니다. 외부 제출 전 전체 영상을 검수하세요.
