Blackbox Mask 0.1.2 — Windows 64비트 시제품
========================================

2026-10-07 소스 수정: Intel NPU 선택 기능을 추가했습니다.
NPU 설치/사용 방법과 검증 한계는 NPU_README_KO.txt를 확인하세요.
아래 CPU 전용 및 검증 기록은 원래 0.1.2 배포본 기준입니다.

1. 실행
이 ZIP의 모든 파일을 한 폴더에 압축 해제한 다음 BlackboxMask.exe를 더블클릭합니다.
EXE만 따로 옮기지 마세요. runtime, models, app.py 등 나머지 파일이 함께 필요합니다.
Python 설치와 인터넷 연결이 필요 없도록 Windows 실행 환경과 AI 모델을 포함했습니다.
관리자 권한을 요구하지 않습니다. 프로그램 실행 중 영상 업로드·원격 API 호출은 없습니다.
최초 시제품으로 코드서명은 없으며, 실제 Windows PC 실행 검증은 아직 하지 못했습니다.
일반적인 Windows 10/11 x64 PC를 목표로 구성했습니다. ARM·32비트 Windows는 대상이 아닙니다.

2. 사용 순서
① [영상 추가]에서 MP4, AVI, MOV, MKV 등 일반 영상을 선택합니다.
② 얼굴·차량 번호판을 선택하고 [1. 선택 영상 분석]을 누릅니다.
③ 프레임 이동/재생으로 원본과 처리 미리보기를 비교합니다.
④ 누락된 부분은 왼쪽 원본 화면에서 마우스로 사각형을 그립니다.
⑤ 필요하면 [프로젝트 저장]으로 보정을 보관합니다.
⑥ [2. 마스킹 MP4 저장]으로 별도 MP4를 만듭니다.

오른쪽 설정이 다 보이지 않으면 오른쪽 패널을 스크롤하세요.
얼굴·번호판 설정 변경은 다음 분석부터 적용됩니다.
블러·모자이크·불투명 가리기, 여유 폭 변경은 미리보기와 출력에 바로 적용됩니다.
워터마크는 최종 저장 시 삽입합니다. 원본/처리 미리보기에서는 표시하지 않습니다.

3. 수동 마스킹과 대상 제외
- 시간 구간(시작/끝 초)을 지정한 다음, 해당 구간 안의 프레임에서 영역을 그립니다.
- 한 번 그린 영역은 지정 구간에 같은 위치로 유지됩니다.
- 움직이는 대상은 목록에서 같은 수동 영역을 선택하고
  [선택한 수동 영역에 현재 위치 추가]를 체크한 뒤 다른 시점에서 새 위치를 그립니다.
- 여러 위치 사이에서는 시간 기준 직선 보간을 합니다. 자동 물체 인식 추적이 아닙니다.
- 처음/마지막 지정 위치 밖의 적용 구간에서는 가장 가까운 위치를 유지합니다.
- 목록의 자동 대상은 [선택 대상 제외 / 복원]으로 전체 추적 구간에서 제외/복원합니다.
  추적 ID가 바뀌거나 다른 객체로 연결될 수 있으므로 제외 구간은 특히 주의해서 확인합니다.
- 수동 대상을 선택한 상태에서 같은 버튼을 누르면 수동 영역이 삭제됩니다.

4. 일괄 처리
[전체 자동 처리]는 목록에 있는 모든 영상을 현재 탐지 설정으로 새로 분석합니다.
현재 영상에 적용한 수동 보정·대상 제외는 일괄 처리에 재사용하지 않습니다.
같은 이름의 결과가 있으면 숫자를 붙여 새 파일을 만듭니다.
영상마다 편집 가능한 .maskproj.json 파일을 함께 저장합니다.
일괄 결과는 모두 '검토 전'입니다. 필요한 경우 프로젝트를 열어 보정 후 다시 출력하세요.
실패 파일은 완료 목록에 구분하여 표시됩니다. 취소 전에 완료된 파일은 남습니다.

5. 출력
- H.264 MP4, 원본 프레임 크기 유지, 프레임 시각/기간을 이용한 출력
- 원본과 같은 경로 저장 금지. 취소·오류 시 미완성 임시 영상을 제거
- 기본적으로 음성 제외. [음성 유지] 선택 시 첫 음성 스트림을 복사
- 음성에는 마스킹이 적용되지 않습니다. MP4와 호환되지 않는 음성 코덱은 실패할 수 있습니다.
- GPS 등 데이터 스트림과 원본 컨테이너 메타데이터는 출력에 복사하지 않습니다.
  영상에 이미 찍혀 있는 GPS·이름·전화번호 등의 문자는 자동으로 가려지지 않습니다.
- 출력물 옆 .mask-report.json에 원본/출력 SHA-256, 프레임 수, 설정, 검토 표시 기록
- 검토 완료 표시는 사용자의 확인 상태입니다. 시스템의 개인정보 무누락 인증이 아닙니다.
- 재인코딩하므로 원본과 화질이 완전히 같지는 않습니다. 원본은 계속 보관하세요.

6. 성능과 현재 한계
얼굴: PINTO model zoo 445 YOLOX-Nano (ONNX)의 머리(head) 탐지
  얼굴만이 아니라 사람 머리 전체를 가립니다. 옆·뒤를 향한 사람의 머리도 가려집니다.
  반사경, 신호등, 둥근 표지 등을 머리로 잘못 가리는 경우가 남아 있습니다.
번호판: Open Image Models YOLOv9-t 640 ONNX
CPU에서 동작합니다. GPU 가속 기능은 이 버전에 포함하지 않았습니다.
모든 디코딩 프레임을 탐지하며, IoU 기반 연결로 추적 ID를 부여합니다.
짧은 탐지 누락에는 이전 영역을 최대 0.2초 유지합니다.
고급 재식별, 카메라 이동 보정, 완전히 가려진 대상 복원은 지원하지 않습니다.
한국 번호판에 대한 별도 학습이나 실제 한국 블랙박스 정확도 검증은 아직 하지 않았습니다.
야간, 작은 얼굴·번호판, 반사·틴팅, 가림, 빠른 움직임에서 누락될 수 있습니다.
작은 번호판 추가 탐지는 원본을 겹치는 구역으로 나누어 탐지하므로 시간이 더 걸립니다.
완전 자동·무누락·익명화 완료를 보장하지 않습니다. 외부 제출 전 전체 영상 검수가 필요합니다.
음성, 상호, GPS 표시, 화면 내 개인정보 문자는 필요 시 별도 처리하세요.
제조사 전용/암호화 포맷, 손상 영상, 중간 해상도 변경, 임의 각도 회전·반사 메타데이터 영상,
홀수 가로/세로 출력, HDR 색 보존, 멀티 카메라 동시 처리는 현재 지원 범위 밖입니다.
90/180/270도 표시 회전 정보는 미리보기·분석·출력에 반영합니다. 90/270도는 가로·세로가 맞바뀝니다.
기존 0.1 프로젝트는 좌표 호환성을 위해 이전 방향을 유지하므로 회전 보정이 필요하면 다시 분석하세요.
영상 스트림이 여러 개이면 첫 번째 영상 스트림만 처리합니다.
긴 영상은 시간과 메모리를 많이 사용합니다. 처음에는 10~30초 영상으로 시험하세요.
미리보기 재생은 PC 속도에 따라 느릴 수 있습니다. 처리속도 측정은 대상 PC에서 해야 합니다.

7. 검증 범위
Linux에서 실제 AI 모델 로딩/추론, 머리 탐지 출력의 좌표 복원·중복 제거,
합성 영상의 마스킹, 프레임 시각/기간, 음성 포함·제외, 원본 보호,
취소 처리, 프로젝트 저장/불일치 차단, 수동 보간 등 테스트 17개 통과. 한글 경로의 모델 버퍼 로딩, 모델 누락·손상 안내 추가 검증.
0.1.2의 얼굴(머리) 모델 교체는 블랙박스 영상 4개에서 뽑은 323프레임을 눈으로 판정한 기준으로 비교했습니다(VALIDATION.txt).
Qt 화면 생성, 수동 영역 생성과 위치 추가, 프레임 이동 확인. 90도 회전 MP4의 미리보기/탐지/출력 방향 일치 추가 확인.
Windows용 실행기는 x64 PE GUI 실행 파일로 교차 컴파일했습니다.
Windows CPython·라이브러리·모델을 묶었으나 Windows에서 실제 실행하지는 못했습니다.
따라서 조직 전체 배포 전에 목표 Windows PC에서 실행·처리·출력을 확인해야 합니다.

8. 문제 확인
실행이 되지 않으면 Diagnose.cmd를 더블클릭해 오류 메시지를 확인합니다.
시작 로그: %LOCALAPPDATA%\BlackboxMask\startup.log
오류 화면/로그를 전달하면 해당 환경에 맞춰 수정할 수 있습니다.
백신이나 조직 정책으로 차단되면 회사 담당자에게 파일 검토를 요청하세요.

9. 소스와 재빌드
app.py: 사용자 화면 / engine.py: 영상·AI 처리 / launch.py: 시작과 오류 기록
models/: AI 모델 / runtime/: Windows 실행 환경 / tests/: 처리 테스트
build/launcher.c: 이 패키지 실행기의 전체 소스
build/build_windows.cmd: Windows Python 3.12 환경에서 PyInstaller로 대체 배포본 생성
build/package_windows.py: 공식 Windows 런타임과 Windows wheel을 이용한 패키징 기록
BUILD_MANIFEST.json: 구성 파일과 다운로드 원본의 SHA-256
THIRD_PARTY_NOTICES.md 및 각 runtime 패키지의 licenses/에는 타사 고지를 보존했습니다.
타사 라이선스는 해당 구성 요소에 적용됩니다. 외부 배포 조건은 별도 확인이 필요합니다.
